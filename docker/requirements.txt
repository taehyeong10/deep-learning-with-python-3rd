# 노트북 실행용 베이스 이미지 의존성.
# 세 백엔드(JAX / TensorFlow / PyTorch)를 모두 GPU 지원으로 설치한다.
# CUDA 라이브러리는 pip 휠(nvidia-*-cu12)로 함께 설치되므로 호스트에는 NVIDIA 드라이버와
# nvidia-container-toolkit만 있으면 된다.
#
# 세 백엔드는 반드시 같은 CUDA 메이저 버전(12)으로 맞춘다. CUDA 12용과 13용 cuDNN 휠은
# 같은 경로(nvidia/cudnn/lib)에 설치되어 서로 덮어쓰기 때문에, 섞으면 한 프로세스에
# cuBLAS 12와 13이 함께 로드되어 행렬 곱이 CUBLAS_STATUS_INVALID_VALUE로 실패한다.
# PyPI의 torch는 CUDA 13 빌드이므로 PyTorch 인덱스의 CUDA 12 빌드(+cu126)를 고정한다.
--extra-index-url https://download.pytorch.org/whl/cu126
